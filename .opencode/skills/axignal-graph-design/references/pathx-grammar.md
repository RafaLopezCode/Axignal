# PATHX Grammar

PATHX is an explainable economic path composed of relationships. A path
`A → B → C → D` must never imply a direct relationship `A → D`. Preserve path
identity, direction and order, and make each constituent edge independently
inspectable with its own nature, epistemic state, time, and evidence.

Emphasize a selected path while attenuating unrelated context without erasing
it. Provide a clear/unselect action that restores the previous useful context.
Support traversal from path segment to evidence and temporal validity. If a
segment is missing, unknown, potential, or historical, communicate that state;
do not smooth it into an observed continuous chain.

Provide a textual sequence with organization names and relationship nature for
keyboard and assistive-technology users. Path highlighting and accessibility
representations are projections; they do not create a direct edge or change
canonical relationships.
