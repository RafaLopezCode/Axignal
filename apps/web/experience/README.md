# AXIGNAL — Living economic observatory

Isolated EXPLORE implementation for visual and interaction review. Branch: `codex/frontend-observatory`.

## Run

Node 24+ and npm. From this directory:

```powershell
npm ci --ignore-scripts
npm run build
npm run start
```

Open http://127.0.0.1:3810. `npm run dev` uses the same loopback address and port. Build output lives under `node_modules/.cache/axignal-next`; source never depends on generated output being committed.

Routes: `/` narrative landing, `/demo` public Observatory example, `/account` subscriber product, `/admin` private Customer Zero and operations, `/design` design system and state gallery, `/sources/[id]` fictitious source documents.

## Admin

Private first-party operations remain separate from economic memory. Read-model identifiers here are illustrative presentation identifiers, not claims of implemented service integrations. Action review separates the read projection, owning authority/connection status, selected record scope and zero-write demo impact. READ / WRITE / SENSITIVE / CRITICAL requirements remain descriptive; no browser role grants permissions. `/api/admin/action` always returns HTTP 403 `AUTHORITY_REQUIRED`. Real commands require an existing privileged session, owning-service contract, scope, step-up/dual approval where applicable and append-only audit.
