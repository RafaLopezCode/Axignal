# ADR-0075 — Exact Explainable Basis and Narrative Verification

**Status:** ACCEPTED
**Date:** 2026-10-03
**Scope:** AUD-04; ExplainableBasis; EvidenceNarrative; graph references
**Derives from:** MASTER §§15, 17, 23, 54, 56; Engineering Constitution VI, VIII, X, XIV; ADR-0072, ADR-0073, ADR-0074

## Context

EvidenceNarrative previously verified observation identity, source reference and artifact integrity, but trusted caller-supplied excerpt/summary, source type, observed time and graph references. A convincing narrative could therefore preserve correct IDs and bytes while changing semantic meaning.

Material contradictions could also disappear if the caller omitted them from ExplainableBasis.

## Decision

EvidenceNarrative is now built only from exact governed narrative material plus verified graph references.

### Exact material

BasisDatum can bind representation_fingerprint and extraction_fingerprint. Narrative construction receives a NarrativeMaterialResolver that resolves each observation to governed material containing:
- subject and candidate identity;
- source reference and source type;
- observed time;
- exact excerpt/summary;
- considered contribution;
- representation fingerprint;
- extraction fingerprint when semantic extraction exists.

Narrative construction fails unless BasisDatum exactly matches the governed material.

Representation-only observations may legitimately carry no extraction fingerprint, but still require an exact representation fingerprint.

### Considered-evidence ledger

The resolver also returns all material considered for the subject/candidate. Every governed material item classified CONTRADICTS must be present as a contradiction in ExplainableBasis. A caller cannot make a material contradiction disappear by omitting it.

### Graph references

Relationship and PATHX references are not rendered from opaque strings. If a Xignal carries relationship_ref or pathx_ref, EvidenceNarrative requires a NarrativeGraphResolver. The reference must resolve to the correct graph kind and include the authorized subject. Missing or unauthorized refs fail closed.

### Replay

Exact observation replay plus identical governed material produces the same EvidenceNarrative value. Narrative output therefore remains deterministic under idempotent replay.

## Runtime integration

FR-30 binds its homepage BasisDatum to the exact DocumentRepresentation fingerprint and supplies NarrativeMaterial directly from the governed representation generated by the runtime. It is representation-only, so extraction_fingerprint is None.

## Non-goals

AUD-04 does not decide tenant/private evidence reuse authorization or temporal currentness policy. Those remain AUD-05 and AUD-06.

## Consequences

- Correct bytes/IDs are no longer sufficient if the semantic summary/type/version was altered.
- Material contradictions cannot be silently omitted.
- Relationship/PATHX UI steps require governed resolution.
- Exact replay remains stable.
- Narrative explanation is now tied to the exact governed material version it claims to explain.
