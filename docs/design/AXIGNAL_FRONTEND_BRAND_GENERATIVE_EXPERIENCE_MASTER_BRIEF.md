## 0. Executive mandate

Create a coherent production-grade AXIGNAL frontend that feels **sophisticated because of how it thinks, not because it is hard to use**.

The experience must combine immediate comprehension, deep analytical power, distinctive brand identity, memorable narrative motion, Human First cognitive compression and browser-real product quality.

AXIGNAL must not look like a generic SaaS dashboard, CRM, graph viewer, BI template, fintech theme or AI-chat wrapper.

## 1. Product essence

AXIGNAL is an **observing economic brain**. It observes the publicly observable economy, resolves organizations, gathers evidence, connects relationships, tracks change over time, derives explainable interpretations and surfaces what deserves human attention.

It is not a CRM, company directory, workflow suite, editable business profile, task manager, generic chatbot or generic analytics dashboard.

Frontend promises:
- observes the world outside an organization;
- connects scattered public evidence into understandable context;
- remembers what was known, when, and what changed;
- distinguishes observed, potential, inferred, stale, historical and unknown;
- explains how it knows;
- lets users direct attention, never conclusions.

## 3. Human First Cognitive UX

AXIGNAL should present the smallest truthful meaning that supports the user's current task while keeping evidence, uncertainty, time, derivation and context directly reachable.

Semantic depth:
- **GLANCE** â€” what is this, what matters?
- **UNDERSTAND** â€” what changed, why does it matter?
- **REASON** â€” how is this derived, which limits matter?
- **PROVE** â€” which observations, sources, dates and evidence support it?

Hard UX rules:
- meaning before metrics;
- no unnecessary mental joins;
- evidence on demand;
- same truth, different density;
- attention is projection, not truth;
- return restores the investigation, not merely a page;
- ordinary comprehension must not depend on chat;
- never use color alone for epistemic state.

## 5. Fractal navigation

A user can move from broad family to progressively narrower scope while retaining analytical lenses.

Example: Markets â†’ Construction â†’ Rehabilitation â†’ Energy retrofit â†’ Hotels â†’ Madrid.

Interaction grammar:
- click/tap enters;
- back/breadcrumb returns;
- wheel/trackpad may move among siblings;
- explicit arrows provide accessible equivalent;
- timeline changes global temporal context;
- AXENT can navigate/explain but is not the only navigation mechanism.

## 6. Spatial architecture

**LEFT = product navigation.** Stable and non-generative: profile, organizations, settings, subscription.

**CENTER = generative observation canvas.** What the user is observing now.

**RIGHT = AXENT.** Explain, investigate, navigate, open evidence and contextualize. Never truth authority.

**BOTTOM = global timeline.** Temporal control across the whole relevant projection.

**TOP = traversal.** Back, forward, home, breadcrumb/focus trail.

## 7. Generative UI architecture

Target: **governed Generative UI**, not arbitrary AI-generated frontend code.

Pipeline: canonical state â†’ semantic projection â†’ attention projection â†’ UI plan â†’ governed component registry â†’ deterministic layout â†’ React UI.

JEV may decide attention, semantic priority, size class, presentation archetype, placement intent and what can remain hidden.

JEV must not decide canonical truth, convert potential into observed, write AXIGLAND, invent evidence, own raw pixel coordinates or generate unrestricted JSX as authority.

Recommended semantic hints:
- size: XL / L / M / S
- placement: CENTER / NEAR_CENTER / SUPPORTING / PERIPHERAL
- role: PRIMARY / SECONDARY / CONTEXT / DETAIL / HIDDEN

Deterministic responsive layout owns actual placement. Avoid overcrowding, giant dead zones and layout jitter. Use visual hysteresis so small priority changes do not make the dashboard dance.

## 11. Color system

Primary dark neutral: **#3c3c3c**.

Palette philosophy:
- creative freedom in hue;
- saturation around **20%**;
- lightness around **70%**;
- calm, luminous, editorial colors;
- muted sage, dusty blue, soft lavender, muted terracotta, sand, powder rose, desaturated olive and similar families.

Avoid neon, saturated SaaS gradients, loud marketing palettes and childish candy color.

### Bic-blue accent

Handwritten annotations and the proposed monocle/isotipo use a **Bic-ballpoint-like blue** as distinctive editorial accent. Derive the production token from approved source artwork, not screenshots. Use intentionally, not everywhere.

## 14. The Observer â€” canonical character

The Observer is a visual embodiment of observation. It is **not AXENT** and not a cartoon mascot.

Archetype: meticulous, calm, studious analytical detective; more detective/analyst than explorer/adventurer.

Mandatory invariants:
- abstract line-based figure;
- very simple body;
- no realistic anatomy;
- no Pixar/Disney/cartoon rendering;
- no 3D toy look;
- no detailed hair, beard, skin or clothing;
- classic flat/newsboy cap;
- two eyes conceptually present;
- one eye visually simple/free;
- one single monocle/lens over the other eye;
- monocle is the brand isotipo itself;
- **no chain/string**;
- Observer **holds the monocle with one hand** when in use;
- notebook/tablet optional recurring prop;
- main line work dark/charcoal;
- monocle + handwritten notes in Bic blue;
- recognizable at small scale.

Communicate personality through posture: look toward a card, lean into evidence, think quietly, point to a change, accompany focus transitions and walk/reposition deliberately.

Avoid comedy, cute gestures, noir clichÃ©s, constant motion and theatrical detective costume.

## 20. Responsive behavior

Wide desktop: constellation + left nav + AXENT rail + full timeline.

Narrow desktop: fewer simultaneous cards and adaptive spacing.

Tablet: reduced constellation, editorial columns, AXENT drawer/panel.

Mobile: narrative stack; do not shrink desktop constellation. Preserve semantic depth and evidence paths.

## 21. AXENT boundary

AXENT is conversational investigation/orchestration. The Observer is visual attention/observation. Do not conflate them.

## 22. Timeline

Time is global. Timeline supports current/historical state, changes, checkpoints, evolution and context restoration. Moving time should re-project all relevant state, not only a bottom chart.

## 23. Admin

Admin shares the same design language but may be denser. It must not look like a different product. AXIGNAL internal CRM/account/payment state must remain structurally and visually distinct from canonical economic truth.

## 24. Required states

Design loading, researching, partial, empty, unknown, stale, contradiction, potential, observed, historical, permission denied, network/tool error, retry, reduced motion, no evidence and unsupported comparison.

Never encode these with color alone.

## 25. Accessibility

Require keyboard navigation, visible focus, touch targets, screen-reader labels, reduced motion, no hover-only critical actions, no handwritten-only essential information, semantic HTML, chart alternatives and responsive text scaling.
