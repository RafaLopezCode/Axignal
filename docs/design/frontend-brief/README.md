# Frontier Visual Reference Pack

**Status:** CANONICAL REFERENCE MANIFEST  
**Date:** 2026-10-03

The Frontier handoff includes this canonical visual specification in addition to the master brief. The approved rendered character sheets from the design conversation must be supplied alongside it; this manifest governs their consistency.

## Canonical direction

- Same Observer in every sheet.
- Abstract line character.
- Flat/newsboy cap.
- Two eyes conceptually present.
- One eye simple/free.
- One single monocle.
- The monocle is the AXIGNAL isotipo itself.
- No chain/string.
- Observer holds the monocle with one hand when using it.
- Dark charcoal line work.
- Monocle/isotipo and handwritten notes in Bic-blue.
- Notebook/tablet may appear as secondary prop.
- No Pixar, 3D toy, photorealism, detailed human anatomy or style drift.
