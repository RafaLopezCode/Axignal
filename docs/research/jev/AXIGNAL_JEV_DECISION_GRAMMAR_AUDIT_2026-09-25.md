All 12 questions are auditable and content-locked. “Actual available state” distinguishes source corpus record from the provider state. ## Cross-cutting grammar findings

1. All 12 declare the same `decision-state.v0.1` and four generic relevant paths even when task needs a claim and passage, entity pair, or relationship endpoints/evidence. Field presence and semantic resolution are not validated against question requirements.
2. Actual criteria are null for all Choice categories. For #11/#12 instructions partly define answer meanings; the enum alone still has no independent descriptions. Score criteria are ordered but generic/non-equivalent across families. Noul proposition text exists, but no explicit state semantic path guarantees its arguments are present.
3. `UNRESOLVED` is present in some Choice spaces, but missing-input, no evidence, not applicable and ambiguity are not consistently distinguishable at the answer-space/composition boundary. Noul cannot encode typed reason distinctions alone.
4. Grammar mixes candidate comparison variants (same family, different primitive/wording/atomicity) with canonical question families. Future evaluation must state which questions are alternatives and map their outputs to a common estimand without erasing primitive-specific information.
5. No grammar item currently specifies a machine-checkable minimum information set. A declarative contract plus preflight is a derived control, not a vendor API requirement.
