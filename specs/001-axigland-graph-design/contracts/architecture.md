# Architecture Acceptance Contract

The accepted boundary is:

```text
Canonical AXIGLAND → AXIGNAL graph projection → AXIGNAL semantic cartography
→ AXIGNAL renderer contract → replaceable adapter → Sigma + Graphology (initial)
```

Required invariants:

- AXIGNAL owns semantic LOD, hierarchy, projection, epistemic/temporal grammar,
  relationships/PATHX, corporate structure, clustering, focus, progressive
  materialization, labels, accessibility, anomalies, and evidence inspection.
- The renderer owns mechanical drawing and renderer-local mechanics only.
- Sigma/Graphology types do not cross the adapter boundary into canonical
  domain, evidence, cognition, JEV, temporal, acquisition, resolution, review,
  or anomaly authorities.
- UNKNOWN != FALSE; POTENTIAL != OBSERVED; PATHX != direct relationship;
  REVIEW != EDIT.
- No production graph dependency or runtime renderer is added by this contract.
- Cosmos is historical bakeoff evidence only and cannot be an allowed
  production dependency under its CC-BY-NC-4.0 license.

The exact runtime projection schema remains intentionally unspecified.
