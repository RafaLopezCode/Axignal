# Conceptual Data Model

This design slice defines no runtime schema. These concepts identify semantic
boundaries only and must not be translated into renderer-owned canonical types.

| Concept | Meaning | Authority |
| --- | --- | --- |
| Canonical AXIGLAND | The economic world and its governed facts/relationships | AXIGNAL domain and evidence authorities |
| Graph projection | A query-shaped view of selected world context | AXIGNAL projection semantics |
| Semantic cartography | LOD, hierarchy, visual grammar, focus, clusters, labels, and accessible complement | AXIGNAL |
| Renderer contract | Boundary for drawing an AXIGNAL projection and relaying mechanical input/output | AXIGNAL-owned contract, future implementation |
| Renderer adapter | Replaceable implementation of mechanical rendering | Initial Sigma + Graphology; not truth authority |
| PATHX | Ordered explainable path through constituent relationships | AXIGNAL domain semantics |
| Evidence trace | Derivation → FAXTs → evidence → source lineage → time/currentness | Evidence and provenance authorities |

Projection, visual state, selected focus, layout, and renderer graph objects are
not canonical truth and cannot write to the domain.
