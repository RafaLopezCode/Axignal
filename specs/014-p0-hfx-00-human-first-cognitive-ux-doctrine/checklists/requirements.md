# Requirements Checklist: P0-HFX-00

## Product doctrine

- [x] One MASTER defines Human First as a core product capability.
- [x] Cognitive Jevons is explicitly a CTO/product hypothesis, not scientific
  or economic law.
- [x] Interpretation Debt, Expertise Tax and Human Cognitive Amortization are
  identified as AXIGNAL concepts/hypotheses, not validated measures.
- [x] Cognitive Compression, Semantic Zoom, Navigation, Continuity and
  Provenance are defined with epistemic limits.
- [x] Direct depth jumps are preserved; no required wizard is specified.
- [x] No mental joins, meaning before metrics and evidence-on-demand are stated
  without allowing unsupported composite conclusions.
- [x] Same truth serves expertise levels; no novice-specific truth.
- [x] Attention priority is a projection, not canonical truth.

## Taxonomy and Human Output

- [x] Human-level taxonomy includes Identity, Capabilities, Products/Services,
  Markets/Reach, Relationships, Activity, Demand, Projects/Procurement,
  Opportunities, DRI, Public Experience, Competition, Change and Evidence.
- [x] Four DRI families from MASTER §54/ADR-0014 are preserved.
- [x] Semantic, epistemic, temporal, attention and archetype axes remain
  independent.
- [x] Human Output Contract is conceptual; no runtime class/schema created.
- [x] Professional metric meaning, definition and interpretation boundary are
  included where material.

## Continuity, privacy and security

- [x] AXIGLAND, Xeed germination context and private cognitive memory separated.
- [x] Continuity is distinct from cognitive provenance; missing origin is
  UNKNOWN and then-state is not overwritten.
- [x] Client_context boundary, default client scope, explicit authorized
  portfolio scope and context-version stale-response control documented.
- [x] Typed AXENT Context Broker target; no direct DB/arbitrary SQL authority.
- [x] Private memory cannot mutate AXIGLAND; EvidenceAdmission preserved.
- [x] Sensitive psychological profiling prohibited; retention/deletion and
  embedding inheritance included.
- [x] Cross-client, portfolio, deep-link, stale-response and private-to-public
  security tests specified.

## Research, accessibility and technical hypotheses

- [x] Empirical HCI evidence, established guidance, inference, CTO hypothesis
  and canonical decision are distinguished.
- [x] Research is source-backed and reports study population/task limitations.
- [x] WCAG 2.2 AA target plus COGA-informed user research documented; no claim
  of complete cognitive usability from conformance alone.
- [x] PostgreSQL + pgvector is a hypothesis/recommendation, not a selected DB.
- [x] RLS owner/privileged-role caveat and pgvector approximate filtering caveat
  documented.
- [x] No unnecessary graph/vector/search/cache store is selected.
