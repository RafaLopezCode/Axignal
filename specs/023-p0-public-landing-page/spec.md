# Feature Specification — P0 Public Paginated Landing Page

**Status:** PREPRODUCTION AUTHORITY
**Canonical product contract:** `docs/product/AXIGNAL_PUBLIC_LANDING_PAGE_CONTRACT.md`
**Execution authority:** `MASTER_EXECUTION_ORDER_V2.md`

## Objective

Deliver a public 15-chapter AXIGNAL acquisition experience that converts through comprehension, evidence-aware trust and differentiated editorial visual storytelling.

The feature must not create new economic truth, subscriber authority, billing claims or runtime capabilities.

## Required chapter order

`OUTSIDE → OBSERVE → UNDERSTAND → AXIGLAND → XIGNAL → FIRST_MAP → EVIDENCE → DISCOVER → DIGITAL_REPRESENTATION → TIME → AXENT → INDEPENDENCE → USE_CASES → PRICING → START`

## Preproduction gates

1. `COPY_FREEZE`: EN 15/15 + reviewed ES 15/15.
2. `STORYBOARD_FREEZE`: 15/15 coherent desktop/tablet/mobile compositions with rendered verification.
3. `SOURCE_MANIFEST_VERIFIED`: all external masters match approved hashes.
4. `ASSET_PIPELINE_VERIFIED`: WebP 15/15; AVIF candidates governed by quality/performance evidence.

## Implementation scope

- public route;
- persistent header;
- 15 chapters;
- six locale catalogs: en/es/fr/de/it/pt;
- CJK-ready content architecture;
- native/bounded chapter pagination;
- responsive focal metadata;
- reduced motion;
- truthful CTA routing;
- SEO metadata;
- browser QA and deterministic tests.

## Explicit non-scope

- domain truth changes;
- EvidenceAdmission changes;
- subscriber AXIGLAND changes;
- Settings/account runtime;
- billing implementation;
- AXENT runtime;
- production deployment;
- Golden Master changes to subscriber product.

## Acceptance

The implementation is not review-ready until COPY_FREEZE and STORYBOARD_FREEZE are satisfied and the browser-rendered product passes canonical claim, responsive, locale, accessibility, interaction and performance review.
