## Intent and clarification

Extend the accepted experience Admin without replacing its existing operational
review surfaces. A distinct Use AXIGNAL destination consumes FR-30. Existing
operational examples remain explicitly illustrative, outside the product path.
Organization identity, signals, Today and narrative come only from the persisted
subscriber-safe runtime. No second datastore, canonical writer or Brain.

The canonical HTTPS target is an attention command, never identity evidence.
Legacy endpoints are retained. New reading copy uses organization/signals.
Staff reads require XEEDS_READ; observation commands require RESEARCH_OPERATE.
An existing AO-01 opaque session is transported in an HttpOnly, SameSite cookie;
no new identity provider, role picker or shared server credential is introduced.

## Acceptance

NO_XEED, loading, planting, rejection, insufficient evidence and failure are
distinct. Successful signals expose narrative, safe sources, uncertainty and
currentness. Reload fetches the persisted projection; never localStorage truth.
The first real source acquisition must run through HttpSourceSensor. Acquisition
failure remains insufficient evidence, never a synthetic success.
