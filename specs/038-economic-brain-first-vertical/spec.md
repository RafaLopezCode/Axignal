## User scenario and acceptance

From normalized, evidence-backed public state for a refrigeration organization
and a cold-storage project, derive a capability/need candidate that neither
source explicitly connects. Independently type supplier and customer roles,
functional alignment, capability-specific delivery reach, action window and
required certification. Interpret in Python into POTENTIAL with warranted
attention, or UNKNOWN with investigation/retention. Produce a meaning-first
read model with exact source references, per-dimension basis and limitations.

Deterministic tests must demonstrate an already-admitted observed capability,
an announced need/event, simultaneous supplier/customer roles, missing material
context, contradiction, expired/stale evidence, evaluator failure, malformed
judgment and exact replay. No source activity or classification establishes a
relationship or commercial fit. UNKNOWN is never a negative classification.

## Clarifications resolved from the task

- Start after acquisition, normalization, identity resolution and evidence
  backing; use a wholly synthetic corpus, not a real-world accuracy benchmark.
- One capability and one project per invocation. Candidate generation joins
  these independently sourced states; semantic alignment is bounded judgment.
- Use the existing Choice evaluator port for three independent semantic axes;
  exact reach, dates and certification checks stay deterministic. Mixed
  primitives, batching and provider selection are later work.
- Declared source statements remain DECLARED. Only an existing matching FAXT
  can support OBSERVED business input. This slice never creates a FAXT.
- Missing reach/window/certification or unresolved material contradictions
  block positive opportunity presentation. Price, capacity, incumbent and
  commercial access remain explicitly unassessed, even in a POTENTIAL output.
- The Human Output is an internal public-evidence read model. Subscriber
  authorization and publication remain requirements for its later UI consumer.
