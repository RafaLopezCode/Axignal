# Admin governance UX

## Scope and clarification
Refine all twelve operational Admin sections pictured by the user, including
customer access. Preserve Customer Zero, the AXIGNAL tool and the shared
subscriber/demo canvas. No deployment, financial transaction, new authority,
canonical write or integration activation is authorized.

User clarification (2026-10-15): the review surface must contain no synthetic
operational data and must consult the real owning services. Controlled fixtures
remain permitted in automated tests, but cannot establish real-data acceptance.

## Cognition and authority
The operator opens a private section to understand its state, identify missing
information, and inspect the source before acting. MASTER §2.1A, §5 and §55,
Constitution, ADR-0055/56/57/58 and slice 070 govern this extension. Existing
Fraunces headings, UI sans and AXIGNAL blue remain visual authority. Operational
projections are authorized private reads; grouping/search/paging are presentation
state. Missing values remain unknown, distinct from zero and false. Projection
time is separate from browser fetch time. Unsupported services stay unavailable.

## Acceptance
- All twelve sections: clear title, primary read action, source time, useful
  hierarchy, structured provenance, readable content at desktop and 390px.
- Compact grouped metrics; identifiable records with search and bounded paging.
  Available/partial/unknown data remain distinct without repeated empty cards.
- Governance policies, alerts and audit, financial periods/amounts, integration
  contracts, acquisition attribution and measurement definitions stay inspectable.
- Loading, expired session, denied scope, failed transport and empty results have
  distinct feedback and appropriate recovery. Failed refresh hides stale reads.
- Browser history, skip links and domain scroll reset work. Product unchanged.
- Customer forms, tabs and confirmation retain owner-service authority and are
  usable with keyboard, clear labels and consistent feedback.
- Six-language coverage, renderer regressions, frontend checks/build,
  deterministic repository gates and actual controlled browser E2E evidence.
- Material visual acceptance remains pending the human; no automatic Golden Master.
- Verify the twelve real Admin reads through the existing operator channel and
  existing session. No seeded runtime, generated session, fallback example,
  copied production database or new production exposure in the review surface.
  Missing source projections remain unavailable with their exact reason.
