# Presentation data model

No storage, domain entity, canonical truth or API schema changes.

- **PublicFamily**: canonical `FamilyId`; localized human label, question, explanation, evidence types, limitation; existing example link when supported. All ten IDs/order derive from `FAMILY_ORDER`. Import projection types only; do not ship its fictional organization arrays as marketing evidence.
- **PublicIndustry**: stable allowlisted slug; six-language title and argument; practical questions; canonical family references; evidence/coverage caveat; example/access exits. A use context is not a real customer case study.
- **PublicJourney**: public route, canonical URL and localized alternatives. Unknown keys return 404; no arbitrary route interpolation or redirects to caller-supplied destinations.
- **VisualAsset**: local public path, dimensions, alt/decorative role, source/prompt provenance; no source/customer claim is encoded in artwork.

Canonical commercial values come from `EUR_REFERENCE`; no copied price arithmetic. No real company, source excerpt, financial result or temporal observation is authored into this catalog.
