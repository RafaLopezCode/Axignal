# Architecture review

Graphify query (existing primary-workspace graph) locates `robots`, `sitemap`, acquisition, public shell and official `seo_truth_sync`; source and live HTML establish current behavior. The isolated checkout has no generated graph and uses the primary graph for navigation only.

No architecture boundary changes. Metadata is computed server-side from existing locale records and the price book. Favicon redirects are exact aliases in Next and the existing landing fallback; no broader ingress or API exposure. Font headers reuse the approved hashed assets. The assistant directory is static text and conveys no authority to mutate state.

Approved for implementation within the user's SEO/GEO scope. No design-system, doctrine or new ADR change required.
