# Public discovery hardening

Date: 2026-10-21. Status: implementation authorized, including commit, merge and production deployment by the repository owner.

## Intent and authority

Make AXIGNAL's existing public experience accurately discoverable and understandable by search engines, social previews and retrieval-based assistants. MASTER §§27, 53–55, Constitution, ADR-0014/0015 and existing public acquisition contracts govern this work. This optimizes AXIGNAL's own website; it adds no SEO execution capability to the subscriber product.

## Acceptance

- Every published home and catalog language declares a complete localized title, description, canonical, reciprocal languages and social image/card in server HTML.
- Metadata describes continuous economic intelligence, public evidence, memory and potential opportunities without claiming rankings, citations, customers or outcomes.
- Organization, website, page and service identities form a coherent JSON-LD graph using approved assets and the governed reference price book. Invitation-only access is explicit alongside prices.
- The conventional favicon URL resolves to the existing approved icon; there is no regenerated artwork.
- The public home routes receive the same two essential font preloads as the accepted preview. No animation, body layout, public/private boundary or browser-language preference changes.
- Public HTTP audit, metadata contracts, production build and deterministic repository gates pass before merge. Verify the exact release on production after deployment.

## Non-goals

No synthetic reviews, invented organizational/legal details, keyword stuffing, hidden prose, generated article expansion, provider-specific optimization claims or guaranteed indexing/rich results. No change to crawl permissions for private routes. First-party Search Console evidence remains private; credentials never enter Git or logs.
