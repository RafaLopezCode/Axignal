# One global public header

## Request and authority

The owner reports crowded desktop navigation and a different header after leaving the landing. Replace the divergent public presentations with one shared header and an authored desktop/mobile menu. Mode EXTEND: retain AXIGNAL brand, licensed type, colors, existing destinations and product truth. MASTER → Constitution → ADR-0016/0017 → design doctrine/contracts → this presentation change. This is not a subscriber/product-navigation redesign.

## Required visitor outcome

The visitor recognizes AXIGNAL and can reach any principal public destination without fitting every page into the bar. Header geometry, labels and controls remain the same on home, marketing, articles, contact, policies and access routes. Article translations remain equivalent articles; home translations stay public; isolated previews remain previews. The menu groups landing chapters, deeper pages and trust/newsletter links without inventing pages or claims.

## Acceptance

- LandingLab and PublicShell render the identical PublicHeader outside page-specific style containers; no landing/catalog variant remains.
- Desktop keeps a spacious bar with brand, outlined sign-in, start CTA and explicit Menu control. The native language picker lives in the complete panel; narrow widths move access actions there too.
- A native details/summary disclosure opens an ample two-column panel in desktop and a single-column panel with native scrolling on phones. Essential links work without JavaScript.
- No new animation library, body scroll lock, fake loading, numbered page hierarchy or modal focus trap. Escape returns focus to the summary, pointer outside/focus leaving close it, route changes close it; native keyboard activation and reduced motion are respected.
- Real browser desktop/mobile comparison, keyboard, actual public journeys, route/language continuity, delivered CSS, SEO and performance evidence are required before claiming verified delivery. Automated QA does not grant human visual acceptance.

## Exclusions

Do not activate contact/newsletter channels, alter subscriber/demo navigation, prices, canonical economic state, credentials or private routes. Preserve unrelated work and existing production overlays.
